Politique de confidentialité

Dernière mise à jour : 25 septembre 2026

Colibri est une application de bureau pour Windows, éditée par Thibault Delavelle. Cette page dit quelles données Colibri lit, où il les garde, à qui il les envoie, et comment les effacer. En résumé : vos données restent sur votre ordinateur et chez le fournisseur de votre boîte. L'éditeur de Colibri n'en reçoit aucune.

Ce que Colibri lit

Pour les comptes que vous y ajoutez, et seulement pour vous les montrer et vous laisser les gérer, Colibri accède :

  • à votre courrier : messages, dossiers ou libellés, pièces jointes, brouillons, et à l'envoi de messages en votre nom quand vous le demandez ;
  • à votre agenda : événements, invitations et vos réponses ;
  • à vos contacts ;
  • aux réglages de votre boîte qui s'affichent dans Colibri : réponse automatique d'absence, règles de tri ;
  • à votre adresse e-mail, pour savoir à quel compte vous vous êtes connecté.

Où ces données vont

Colibri communique directement avec les serveurs du fournisseur de chaque compte : Google, Microsoft, votre hébergeur Exchange ou IMAP. Il n'existe aucun serveur de Colibri : aucun message, aucun contact, aucun événement, aucun identifiant n'est envoyé à l'éditeur ni à quiconque d'autre. Colibri ne contient ni publicité, ni mesure d'audience, ni rapport d'utilisation.

Deux exceptions, que vous seul déclenchez :

  • L'assistant IA, si vous le configurez. Quand vous lui demandez de trier, relire ou résumer, Colibri envoie le contenu des messages concernés au service Azure OpenAI que vous avez vous-même renseigné, avec votre propre clé. Rien n'est envoyé si vous ne le configurez pas, ni sans une action de votre part.
  • Le serveur pour assistant (MCP), livré avec Colibri. Si vous le déclarez dans un agent IA installé sur votre ordinateur, cet agent peut lire votre boîte et y écrire un brouillon quand vous le lui demandez. Il ne peut ni envoyer, ni supprimer, ni déplacer de message. Ce que l'agent fait ensuite de ces données dépend de son propre éditeur.

Les images distantes contenues dans un message ne sont affichées que si vous l'autorisez, car les charger prévient l'expéditeur que le message a été ouvert.

Ce que Colibri garde sur votre ordinateur

  • Vos mots de passe et jetons de connexion, chiffrés par Windows (DPAPI) et lisibles uniquement par votre session Windows, sur cet ordinateur ;
  • la liste de vos comptes et les serveurs à joindre ;
  • vos réglages : apparence, signatures, préférences d'affichage ;
  • un carnet des adresses avec lesquelles vous avez échangé, pour la saisie automatique des destinataires ;
  • les pièces jointes que vous ouvrez, le temps de les afficher, et le cache du composant d'affichage de Windows (WebView2).

Tout se trouve dans le dossier %LOCALAPPDATA%\Colibri de votre session. Vos messages eux-mêmes restent chez votre fournisseur : Colibri ne copie pas votre boîte.

Effacer vos données

  • La désinstallation de Colibri supprime toujours les mots de passe, jetons de connexion et clés enregistrés, et propose de supprimer le reste du dossier %LOCALAPPDATA%\Colibri.
  • Vous pouvez aussi retirer l'accès de Colibri à tout moment chez le fournisseur : pour Google, sur myaccount.google.com/permissions ; pour Microsoft, sur account.live.com/consent/Manage (compte personnel) ou myapps.microsoft.com (compte professionnel).
  • Rien n'étant conservé ailleurs que sur votre ordinateur, il n'y a rien d'autre à effacer.

Données Google

L'utilisation et le transfert à toute autre application des informations que Colibri reçoit des API Google respectent le Règlement sur les données utilisateur dans les services d'API Google, y compris ses exigences d'usage limité. Colibri n'utilise vos données Google que pour vous afficher et vous laisser gérer votre courrier, votre agenda et vos contacts ; il ne les vend pas, ne s'en sert pas pour de la publicité, ne les utilise pas pour entraîner un modèle d'IA, et personne ne les lit.

Colibri's use and transfer to any other app of information received from Google APIs will adhere to Google API Services User Data Policy, including the Limited Use requirements.

Données Microsoft

Pour un compte Microsoft, Colibri se connecte par la plateforme d'identité de Microsoft avec les autorisations que vous accordez à la connexion, et n'utilise ces données que dans les conditions décrites sur cette page.

Sécurité

Les échanges avec les serveurs sont chiffrés (TLS) ; Colibri refuse une connexion IMAP ou SMTP non chiffrée. Les secrets ne sont jamais écrits en clair sur le disque.

Enfants

Colibri ne s'adresse pas aux enfants de moins de 15 ans et ne collecte aucune donnée à leur sujet.

Changements et contact

Si cette politique change, la nouvelle version sera publiée ici avec sa date. Pour toute question, ou pour exercer vos droits : hello.colibri.app@gmail.com.
